# 覆盖更新与数据保留

1. 更新前可在“设置 → 完整备份”导出一份 JSON，保存到应用外的位置。
2. 下载官方 Release APK，直接安装更新。不要先卸载旧版，也不要清除应用存储。
3. 更新后核对原账目和余额，保留备份以便换机或恢复。

1.0.5 沿用包名 `com.clottins.dailyledger`、原 Release 签名、数据库文件 `ledger.db` 和 Room schema 1。账目从首版就有 `time` 字段，本次新增选择界面不增加数据库字段，也不执行清库或破坏性迁移。

编辑时从原账目读取时间；保存更新原记录 ID，原有分类、退款关联和设置继续保留。取消时间选择会放弃这次待选日期、时间。JSON 与标准 CSV 仍携带时间字段。

自动化检查包含重新打开已有文件数据库、修改一笔时间后保留其他记录、退款关联、分类及余额设置，以及 JSON / CSV 时间往返。此为数据库兼容性回归测试；尚未替代真实手机上从旧版 APK 安装更新的设备验收。构建与签名检查见 [验证记录](TESTING.md)。
